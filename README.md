# 教材のページ

このブランチには，各回の教材のページを置いています．ブラウザで開くときは https://kokiwakatsuki.github.io/member-list-tutorial/ から．

| 場所 | 中身 |
|---|---|
| `index.html` | 全10回の一覧 |
| `01/pc-setup.html` | 第1回「パソコンの準備」 |
| `pc-setup/` | 「パソコンの準備」のコピーボタンで写す1行のコマンドが読み込む中身．どれも確かめるだけで，何も入れず，何も変えない |

作るアプリの出発点は `main`，各ステップの手本は `step-` で始まるブランチにあります．
