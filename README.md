# メンバー名簿をつくる

メンバー名簿のページを1ステップずつ作りながら，Web 開発の道具を覚えていく教材です．

## 始め方

- Git を使う前：緑の「Code」→「Download ZIP」．ZIP を開いて，`index.html` をブラウザで開きます
- Git を使うようになったら：緑の「Use this template」→「Create a new repository」で，自分のリポジトリを作ります．名前は `member-list` にします．「Include all branches」にはチェックを入れません（入れると，手本も一緒に写ります）

## 手本の見方

手本は，[元のリポジトリ](https://github.com/KokiWakatsuki/member-list-tutorial)の，`step-` で始まるブランチに入っています．番号がステップの順番です．

- 左上の「main」と書かれたボタンでブランチを選ぶと，そのステップを終えたときのファイルが見られます
- ブランチを選んでから「Commits」を開くと，各ステップの説明と，変えたところが見られます．緑の行は足したところ，赤の行は消したところです
